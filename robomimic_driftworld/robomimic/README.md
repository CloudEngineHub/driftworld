## Robomimic Library

This folder contains a slightly modified version of the [Robomimic v0.5 library](https://github.com/ARISE-Initiative/robomimic/tree/v0.5).

You can download and process the dataset by running
- `download_raw_data.sh`
- and then `extract_obs_from_raw_data.sh`
- and then `create_split.sh`
